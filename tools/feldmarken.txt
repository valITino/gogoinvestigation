# Feldmarken für tools/pseudonymisieren.py
#
# VORLÄUFIG. Diese Liste enthält übliche Marken aus Formularen und Rapportköpfen. Sie ist nicht die Liste
# eurer Rapporte. Die Messwerte im README gelten für genau diese Datei. Wer die Liste ersetzt, misst neu:
#     python3 tools/pseudo_messen.py
#
# Eine Zeile je Marke:   Marke ; Typ ; Teil
#
#   Marke   So, wie sie im Dokument steht. Gross/klein, ein Doppelpunkt am Ende, ein Punkt bei Abkürzungen und
#           Leerzeichen um «/» und «,» spielen keine Rolle. «Name/Vorname» ist eine eigene Marke.
#   Typ     PERSON, ORG, ADRESSE, TEL, EMAIL, GEBDAT, AHV, KONTO, KFZ, AUSWEIS, DOMAIN, IP
#   Teil    nur bei PERSON und ADRESSE, sonst leer:
#             PERSON   name               voller Name, Reihenfolge offen («Hans Muster» oder «Muster Hans»)
#                      nachname, vorname  je ein eigenes Feld. Stehen sie nahe beieinander, ergeben sie eine Person.
#                      nachname-vorname   beides in einem Feld, Nachname zuerst («Muster Hans», «Muster / Hans»)
#                      vorname-nachname   beides in einem Feld, Vorname zuerst
#                      kuerzel            Kürzel einer Person («mus»)
#             ADRESSE  adresse            ganze Adresse («Dorfstrasse 12, 8000 Zürich»)
#                      strasse, ort       je ein eigenes Feld («Dorfstrasse 12» und «8000 Zürich»)
#
# Der Wert hinter einer Marke wird gelesen, wenn er auf derselben Zeile steht (mit oder ohne Doppelpunkt), auf der
# nächsten Zeile oder in der nächsten Tabellenzelle. Steht in einer Tabelle die Marke im Spaltenkopf, gilt sie für
# die Zeilen darunter. DOMAIN und IP nur für Marken eintragen, hinter denen die Infrastruktur der Geschädigten
# steht: Was dahinter steht, wird ersetzt und lässt sich danach nicht mehr abfragen.
